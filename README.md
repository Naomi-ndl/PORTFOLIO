## Contenu du site

- **Accueil** : présentation, compétences et CV téléchargeable (`cv.pdf`).
- **Projets** : 3 projets Python avec description, technologies et lien GitHub.
  - Amazon Scraper (Python, Selenium, CSV)
  - Analyse comparative de marché (Python, Pandas, OpenPyXL)
  - Biblio IIT (Python)
- **Contact** : e-mail, GitHub, LinkedIn et formulaire de contact.

## Technologies

- HTML5 
- CSS3 (`style.css`) avec un site adapté au mobile (responsive)
- Bootstrap 5 (grille, menu, formulaire)
- jQuery (`script.js`) : vérification et envoi du formulaire de contact
- Git et GitHub Pages pour la mise en ligne

## Structure du dépôt

| Fichier | Rôle |
|---|---|
| `index.html` | Page d'accueil |
| `projets.html` | Page des projets |
| `contact.html` | Page de contact avec formulaire |
| `style.css` | Styles personnalisés |
| `script.js` | Script jQuery du formulaire |
| `cv.pdf` | CV téléchargeable |
