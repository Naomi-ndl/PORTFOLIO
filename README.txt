PORTFOLIO DE NAOMI NDOLI
========================

Fichiers :
- index.html : accueil et présentation
- projets.html : présentation homogène des trois projets avec liens GitHub
- contact.html : coordonnées et lien e-mail direct
- style.css : styles et adaptation mobile
- script.js : fichier de script minimal
- cv.pdf : CV original conservé

Pour visualiser le site :
1. Extraire le dossier portfolio.
2. Ouvrir index.html dans un navigateur.
3. Une connexion Internet est nécessaire pour charger Bootstrap et les polices.

Les trois cartes de projets utilisent la même structure et leurs contenus sont alignés.
